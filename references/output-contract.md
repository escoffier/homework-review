# 归档和输出约定

## 目录与日期

以下路径均相对于 `SKILL.md` 中确定的归档根目录，不依赖固定机器路径或技能安装目录。沿用该目标的现有约定；没有约定时使用：

```text
assignments/YYYY-MM-DD/科目/   原始作业
solutions/YYYY-MM-DD/科目/     逐题批改报告或全卷答案详解
review/YYYY-MM-DD/科目/        双版PDF及Markdown源文件
assets/YYYY-MM-DD/科目/        必要辅助图示
```

默认使用北京时间提交日期；用户指定日期优先。试卷标题日期不同则在文档中另记，不改变提交归档日期。科目从题目内容判断，不明确时询问。同日同科目编号从作业01、作业02递增；补页沿用原编号。识别同一文件的重复提交，避免重复归档。

统一文件名前缀 `YYYY-MM-DD_科目_作业NN`：

| 输出 | 后缀 |
|---|---|
| 多页原题照片 | `_原题_p01.jpeg`、`_原题_p02.jpeg` |
| 原题PDF或文档 | `_原题.pdf`、`_原题.docx`（保留原文件类型） |
| 完整批改 | `_批改.md` |
| 空白试卷全卷答案详解 | `_全卷答案详解.md`、`_全卷答案详解.pdf`（位于 `solutions/`） |
| 解析题源与PDF | `_错题_解析版.md`、`_错题_解析版.pdf` |
| 练习题源与PDF | `_错题_练习版.md`、`_错题_练习版.pdf` |
| 修订输出 | 类型后加 `_v02`、`_v03`，再加扩展名 |

不要覆盖已有不同提交或修订版。原输入的归档及编号映射在报告中记录。保留图片内容，不在原图上写判定。PDF不必要地重复学生姓名、班级或学号。

## 批改报告

开头记录提交日期、科目、作业编号、试卷日期、原始文件列表。用表格列出每个题号或小问的原作答、判定、正确答案和说明。错题详细部分按原题号排列；没有可靠识别的作答标“待核对”，空白标“未作答”。

## 空白试卷全卷答案详解

开头记录提交日期、科目、作业编号、试卷标题或印刷日期、原始文件列表及模式“全卷答案详解”。按原题号逐题、逐小问包含：完整题干与必要图示、参考答案、详细推导或解题过程。共用条件随题保留，保证无需另开原卷也能阅读；待核对题注明原因，不能填入猜测答案。可加答案速查表，但不能替代逐题详解。

源稿与PDF同名放在 `solutions/YYYY-MM-DD/科目/`，沿用统一前缀及版本号规则。索引记录任务类型、原题链接、详解Markdown与PDF链接；沿用现有索引表结构时，批改及错题两版栏标“不适用”，不得伪造链接。此模式无需生成批改报告或双版错题文件，除非用户同时要求。

## 解析版

每条复习记录包含：原题号、完整题干和必要图示、原作答、判定、错误原因或未完成状态、正确答案、逐步解法、知识点。不要将仅有解法的记录称为完整原题。明确区分确定错误、漏项、未作答和辨识不确定。

## 练习版 Markdown

以下结构用于保存真实题目；排版器可根据题量和需要选择分页，示例中的标记不要求使用固定脚本。

```markdown
# 数学错题复习练习
提交日期：YYYY-MM-DD　作业编号：NN
姓名：________　复习日期：________

## 第5题
完整题干。
A. ……　B. ……　C. ……　D. ……
![必要的干净图示](相对图示路径)

## 第16题（2）
完整条件和问题。
```

重新转录有批注的题目，不直接把学生答案截图放进练习版。分数、上下标、绝对值、负号、循环点、根号和角标必须正确；可将循环小数改写为明确的展开式并注明循环节，但不得改变数值。图示只含题目给定信息，不能暗示中间步骤或正确答案。

跨题共用的条件必须在练习版再次写出；只选一道子题时不能丢掉公共题干。例如选工资计算第(2)(3)问，仍保留整段工资规则和生产量表。所有题意需独立可解。

## 检查与索引

核对原图和转录文本；两版每个收录题号对应。按题型分配答题空间：填空适量，计算和证明保留过程书写区。视觉检查全部页面；确认中文字体、公式、分页和图形无缺失。练习版检查文本与图片均不泄露答案，不能仅用关键词搜索代替人工判断。

批改模式下，归档根目录的 `README.md` 提交表至少包含：提交日期、科目、作业编号、试卷日期、原题链接、批改链接、解析版链接、练习版链接。修订时索引指向最新版本，旧文件保留。
